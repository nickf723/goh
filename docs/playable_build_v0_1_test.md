# Grace of Humanity Playable Build v0.1 QA

## Goal

Verify that the Church Trial vertical slice behaves like a standalone prototype rather than an editor-only test course.

## Editor launch

Run the project normally with `F6`/`F5` as appropriate.

Confirm the configured project startup opens the title screen through:

```text
scenes/levels/prototypes/church_trial_room_v1.tscn
```

The integrated Church Trial itself remains directly runnable at:

```text
scenes/levels/prototypes/prototype_boss_dungeon_chain_v1.tscn
```

## Title screen

1. Confirm the title reads `GRACE OF HUMANITY`.
2. Confirm `v0.1.0 Prototype` is visible.
3. Confirm the menu contains:
   - New Trial
   - Continue
   - Controls
   - Quit
4. Confirm New Trial begins with keyboard/controller focus.
5. Confirm the mouse cursor is visible on the title screen.
6. With no save file, confirm Continue is disabled.

## Controls panel

1. Choose Controls.
2. Confirm the gameplay reference is readable at the current window size.
3. Confirm Back returns to the main buttons.
4. Open Controls again and press Escape.
5. Confirm Escape closes the panel without starting gameplay.

## New Trial

1. Create or retain an existing Church Trial save.
2. Return to the title screen by restarting the project.
3. Choose New Trial.
4. Confirm the old save is removed.
5. Confirm runtime flags, key items, and stats reset.
6. Confirm Grace starts at the beginning of:

```text
scenes/levels/prototypes/prototype_boss_dungeon_chain_v1.tscn
```

7. Confirm the Church Trial Sigil is absent from Inventory.
8. Confirm the dungeon begins with its fresh opening objective.

## Continue from entry checkpoint

1. Start a New Trial.
2. Sleep at the Entry Save Bed.
3. Restart the project to return to the title screen.
4. Confirm Continue is enabled.
5. Choose Continue.
6. Confirm Grace loads the entry scene at the saved bed position with saved resources and objective.

## Continue from boss-finale checkpoint

1. Complete combat, the element lock, and the Sound Reveal bridge.
2. Enter the focused boss finale.
3. Sleep at the Armor Trial Bed.
4. Restart the project.
5. Choose Continue.
6. Confirm the boss-finale scene loads directly.
7. Confirm Grace appears at the Armor Trial Bed.
8. Confirm death retry still returns Grace to that checkpoint.

## Reward continuation

1. Defeat the Animated Armor.
2. Claim the Church Trial Sigil.
3. Restart the project.
4. Choose Continue.
5. Confirm Grace resumes from the reward altar save.
6. Confirm the sigil remains in Inventory.
7. Confirm the final exit accepts the persisted key item.

## Editor-only reset shortcut

In editor play only:

1. Open the integrated Church Trial entry scene directly.
2. Confirm the opening/resume message mentions `F8`.
3. Press `F8`.
4. Confirm the prototype save clears and the scene restarts fresh.

In an exported build:

1. Confirm no opening or resume message advertises `F8`.
2. Press `F8` during the entry scene.
3. Confirm it does not reset the save or scene.
4. Confirm New Trial on the title screen is the visible clean-reset path.

## Full exported run

From the downloaded Windows artifact:

1. Extract the ZIP generated by GitHub Actions.
2. Launch `GraceOfHumanity-v0.1.0.exe`.
3. Confirm the title screen opens without Godot installed.
4. Choose New Trial.
5. Complete the full route:

```text
entry/save → combat → elemental lock → Sound Reveal bridge → boss checkpoint → Animated Armor → sigil → exit
```

6. Confirm the title menu and all three gameplay scenes transition correctly.
7. Confirm Continue works after closing and relaunching the executable.
8. Confirm Quit closes the executable from the title screen.

## CI artifact

Open the latest `Godot validation` workflow run for the PR or `main`.

Confirm these steps pass:

- Validate custom agent profiles
- Install Godot 4.6 and export templates
- Import project headlessly
- Start project headlessly
- Export Windows v0.1 build
- Upload Windows v0.1 artifact

Confirm the run exposes an artifact named:

```text
GraceOfHumanity-v0.1.0-windows
```

## Creative review

Judge whether:

- the title screen is calm and readable;
- the four actions are immediately understandable;
- Continue communicates its disabled state cleanly;
- the Controls reference is useful without feeling dense;
- New Trial feels like an intentional clean restart rather than a developer reset;
- the exported build feels coherent enough to hand to a first outside playtester.

## Known limitations

- Prototype UI and icon only.
- No settings, remapping, accessibility menu, save slots, confirmation dialog, music, animation, installer, signing, or platform storefront integration.
- Windows x86_64 export only.
- GitHub Actions artifacts are retained for 14 days.
